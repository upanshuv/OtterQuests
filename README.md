Stay organized. Complete tasks.

OtterQuests is a productivity checklist app designed to help you plan your day, track progress, and stay motivated. Create tasks, manage group productivity, set your goals, organize your list, and watch your progress add up.

OtterQuests makes managing your personal life, school, work, and your family's chores much easier with the features built right in.

**Plan Your Day**
Create and manage tasks with a full calendar system:
• Day, Week, and Month calendar views
• Set tasks for any date and time
• Set reminders for scheduled tasks
• Organize tasks with categories
• Choose a task's priority level
• Delete tasks with a single tap

**Work Together With Groups**
Stay productive with others using Groups. Create or join a group, assign tasks, and compete on a shared leaderboard.
• Create a group right from your Profile tab
• Invite others with a shareable join code
• Assign tasks to your group so every member sees them
• Earn group points by completing group tasks
• Track group productivity on the leaderboard

**Progress Rewards**
OtterQuests turns productivity into a rewarding experience. Complete tasks to earn Rocks — an in-app currency for unlocking customization — and gain XP to level up as you go.

Rocks
• Earn Rocks by completing tasks
• Timed tasks reward Rocks only when completed on time
• Tasks with no scheduled time always reward Rocks when completed

XP
• Every completed task earns XP
• XP is capped daily to keep progress consistent
• Level up every 50 XP
• Track your level and progress from your Profile tab

**Customize Your App**
Visit the Shop to unlock:
• 11 unique background themes
• 11 completed-task icons
• Unlock items using the Rocks you've earned

**See Your Growth**
Your Profile keeps everything in one place:
• Current level and XP progress
• Rock balance
• Completed-task history
• Groups you've joined
• Group leaderboards
